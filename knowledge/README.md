# Knowledge

知识管理与学习类 Skills —— 覆盖阅读、研究、检索、写作、知识库构建。

## Skills

| Skill | 说明 | 来源 |
|-------|------|------|

| [book-study](book-study/) | 系统化阅读教练：章节精读、知识编译、苏格拉底式测试、间隔复习 | sanyuan-skills |
| [hv-analysis](hv-analysis/) | 横纵分析法深度研究：纵向时间线 + 横向竞品对比，产出 PDF 报告 | khazix-skills |

| [khazix-writer](khazix-writer/) | 卡兹克风格公众号长文写作（对话式、反 AI 味、故事驱动） | khazix-skills |
| [prompts](prompts/) | 横纵分析法纯文本提示词模板，可在任意 Deep Research 模型中使用 | khazix-skills |

## 使用场景

- 跟着 AI 系统化地读完一本书
- 对某个主题进行深度研究并产出报告
- 从本地文档库中检索和问答
- 获取 AI 行业每日资讯
- 将素材写成公众号风格的长文
- 构建个人或团队的 Wiki 知识库
