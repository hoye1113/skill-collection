# Agent

Agent 工作空间生成与优化类 Skills。

## Skills

| Skill | 说明 | 来源 |
|-------|------|------|
| [openclaw-agent-forge](openclaw-agent-forge/) | 生成、审查、优化 OpenClaw/FlowyClaw Agent 工作空间，含 IDENTITY/SOUL/AGENTS/TOOLS 根文件映射 | hoye-skills |
| [agent-browser](agent-browser/) | AI Agent 浏览器自动化 CLI：页面导航、表单填写、截图、数据抓取、Electron 桌面应用自动化 | [alchaincyf/openclaw-agent-store](https://github.com/alchaincyf/openclaw-agent-store) |

## 使用场景

- 从一个 Skill 提升为完整的 Agent 工作空间
- 生成或诊断 OpenClaw/FlowyClaw Agent 的根文件
- 规划 Agent 的能力边界、记忆系统、引导流程
- 审查现有 Agent 工作空间的结构合理性
