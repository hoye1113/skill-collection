# 切入角度库

> 30+ 切入角度，按 3 大类组织：非人类视角 / 具体现代职业 / 微观尺度。
> 选角度时优先「具体职业 + 具体场景 + 具体动作」组合。

---

## 第一优先：非人类视角

**优势**：天然去人类中心化，读者不会预设立场。物件/动物/植物/机构在自述，自带疏离感，钩子更稳。

### 工具类（10 个）

| 角度 | 适合的概念类型 | 示例钩子 |
|---|---|---|
| 电梯 | 标准化 / 阈值 / 例外 | 一部电梯每天关过同一个数字 4 千次，直到那一次 |
| 计算器 | 算法 / 递归 / 边界 | 一台老式计算器发现自己算不出某个数 |
| 门锁 | 权限 / 信任 / 边界 | 一把锁守同一扇门 30 年，那天来了陌生人 |

| 压面机 | 标准化 / 损耗 / 边界 | 压面机压了 5 万张皮，最后一张卡住了 |
| 自动售货机 | 概率 / 期望 / 库存 | 自动售货机有天投了三次都没出货 |
| 老式洗衣机 | 时间 / 周期 / 漂洗 | 洗衣机的定时器坏了，转到了 90 分钟 |
| 复印机 | 复制 / 失真 / 衰减 | 复印机复印自己三次，第三张已经看不清 |
| 录音机 | 记忆 / 重放 / 失真 | 录音机录下了一段话，回放时声音变了 |
| 老式座钟 | 节奏 / 误差累积 / 校准 | 老式座钟每天慢 1 秒，三十年后差了几个小时 |

| 章鱼 | 多臂 / 分布式 / 中央控制 | 章鱼的八条臂各做各的，但不知道彼此 |

## 第三优先：微观尺度

**优势**：聚焦一个动作或瞬间，把概念掰开了看。适合需要「拆解机制」的概念。

| 角度 | 适合的概念类型 | 示例钩子 |
|---|---|---|
| 一次交易 | 价格 / 价值 / 信息 | 一笔交易在两个交易员看来价格完全不同 |
| 一次门诊 | 诊断 / 信息 / 决策 | 门诊医生看一个病人 5 分钟，但病人等了 2 周 |
| 一通电话 | 信息传递 / 失真 / 反馈 | 同一句话被三个人转述，第三个人听到的完全不同 |
| 一次拆卸 | 拆解 / 重组 / 边界 | 拆一个旧钟，发现三个齿轮坏了但其他都正常 |
| 一次擦肩 | 概率 / 信息 / 时机 | 两个人在地铁站擦肩而过，都不知道发生了什么 |
| 一次堵车 | 涌现 / 局部规则 / 全局 | 一辆车变道引发了 5 公里的堵车 |
| 一次点单 | 决策 / 信息 / 边界 | 顾客点了一个不存在的菜，服务员怎么反应 |
| 一次退货 | 边界 / 决策 / 边界 | 顾客退了一件没问题的商品，店员怎么处理 |
| 一次签收 | 信任 / 边界 / 责任 | 顾客签收时没看商品，回家才发现坏了 |
| 一次扫码 | 信息 / 隐私 / 边界 | 顾客扫了一个陌生二维码，结果怎么样 |

## 选角度的决策树

```
1. 概念是「机制 / 系统」类？
   → 优先：非人类视角（工具 / 机构）
   
2. 概念是「行为 / 心理」类？
   → 优先：具体现代职业（让人物承载）
   
3. 概念是「瞬间事件 / 动作」类？
   → 优先：微观尺度（一次 X）

4. 如果概念跨类？
   → 用「具体职业 + 微观尺度」组合（如：理赔员的某次签字）
```

## 反例（不该选的）

| 角度 | 为什么不该选 |
|---|---|
| 智者 / 隐士 / 老师 | 角色直接承载「讲道理」功能，破坏寓言 |
| 国王 / 王子 / 公主 | 过度文艺化，脱离现代读者认知 |
| 神 / 仙 / 妖 | 同上，且容易滑向神话套路 |
| 抽象的「时间」「命运」「希望」 | 主角是抽象物 = 散文诗，不是寓言 |
