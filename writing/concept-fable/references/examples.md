# 完整示例库

> 3 个完整示例，演示从概念到寓言到解析到检验问题的完整流程。
> 每个示例包含：概念 → 角度选择 → 寓言 → 概念解析 → 检验问题 → 黑名单自检记录。

---

## 示例 1：沉没成本

**概念**：已经付出且不可收回的成本（如时间、金钱、精力），仍然影响未来的决策。

**角度选择**（参考 angles.md）：
- 候鸟的体能消耗 ❌（拟人化太重，读者预设立场）
- 健身房会员的「再用一次」 ✅（具体现代场景 + 现代人熟悉的决策困境）
- 二手书店的进货 ❌（高度具体但不易共情）
- **采用：剪卡会员制**（健身房 / 美容院 / 餐厅常见的预付费卡）

**切入思路**：
- 预付费卡 = 已经付出但每次用都觉得「这次不算成本」
- 关键动作：剪卡前后的心理变化
- 留痕点：剪到还剩几张时的「这次一定要用完」vs「我为什么还在用」

---

### 寓言

小周三个月前花六百块办了城南那家饺子馆的储值卡——十次，每次能抵十块。

头两次去得很勤。卡上印着「本卡不退不换」，她把卡放在钱包最里层，每次剪掉一格都郑重其事。

第三个月，饺子馆换了厨师。新厨师手艺差一截，饺子皮厚馅少，汤底咸。

她去了第三次，坐在靠窗的位子，把那张卡摸出来。服务员说现在储值卡不能用了，得重新办新卡。

她本该转身就走。但她低头看卡——还剩七格，七十块钱。

她点了份最便宜的素馅饺子。吃了三口，确实不如从前。

她想：反正花了六百，再吃七次才回本。

第四次，她带同事去。同事吃得皱眉。她说习惯就好。

第五次，她一个人去。店里只剩两桌，厨师在后厨玩手机。

第六次，下雨。她本来想去另一家新开的，但路过城南那家，看到霓虹灯还亮着。她进去了。

第七次。她已经不期待味道了。她坐在那里看窗外发呆，饺子凉了也没动。

服务员问她要不要打包。她说不用了，把卡往前一推：「退卡。」

服务员愣了一下：「储值卡不退不换。」

她没说话。站起来走了。

第二天，她收到银行的短信——那家饺子馆跑路了，六百块没处要。

她盯着短信看了半分钟，把手机锁了，去厨房泡了碗挂面。

挂面没味道，但烫。

---

### 概念解析

**沉没成本**（Sunk Cost）：已经付出且**不可收回**的成本（如时间、金钱、精力），按理性决策应当**不再影响未来选择**，但人常因不愿「浪费」已付出的部分而继续投入。

**属于**：行为经济学 / 决策心理学

**核心定义**：沉没成本谬误是「**应该被忽略的成本反而被加权**」——理性决策只考虑未来增量，不为已沉没的过去买单。

**元素映射**：

| 故事元素 | 概念对应 |
|---|---|
| 储值卡（600 块已付、不可退） | 沉没成本（已发生、不可回收） |
| 饺子味道变差 | 增量收益下降（继续投入的回报减少） |
| 「反正花了六百」 | 沉没成本谬误（让过去绑架未来） |
| 7 次吃完（每次都在说服自己「用完」） | 路径依赖（已经走到这一步，硬着头皮继续） |
| 跑路（不可控结局） | 沉没成本最坏情形：不仅回本无望，连成本也成沉没 |
| 最后吃挂面（没味道但烫） | 觉醒后的状态——理性了，但失去了过去 |

### 检验问题

**理解检验**：
> 故事里小周明明在第 3 次就发现饺子变差了，为什么她没有立刻停？她每次去吃，最主要的心理机制是什么？请用一句话回答。

**迁移检验**：
> 假设你正在学一门编程课，已经学了 3 个月（共 6 个月课程），投入了 2000 元学费和大量周末时间。最近发现这门课的内容和你未来想做的方向完全不匹配，但课程承诺学完可以拿到证书。此时你**最不应该做**的决策是什么？请具体说明，并给出你建议的决策。

## 示例 2：幸存者偏差

**概念**：只看到「活下来 / 成功」的样本，忽略了「没活下来 / 失败」的样本，导致系统性高估成功率。

**角度选择**：
- 老兵活动中心 ❌（沉重话题，读者情绪负担重）
- 博物馆的展览 ✅（具体场景 + 直观可见的样本偏差）
- 学校展示成功校友 ❌（与博物馆重复逻辑）
- **采用：纪念展 / 老照片陈列**（让观众自己撞上「没被展示的人」）

**切入思路**：
- 博物馆展示 = 策展人筛选过的样本
- 关键动作：策展人挑选展品的标准 vs 实际死伤比
- 留痕点：展览开幕那天，访客看到的全是归来者，但策展人心里清楚另一半人的档案在哪里

---

### 寓言

老博物馆三楼东侧，要开一个展。

策展人是位干了二十年的老员工。他办公桌上摞着厚厚的牛皮纸档案袋，封面用毛笔写着地名和年代。

馆长让他选 50 张照片参展。他翻了三天，挑出 50 张。

每张照片上的人，都在笑。

有穿军装戴勋章的，有穿棉袄扎绑腿的，有坐在卡车驾驶室挥手致意的。每一张的背面，老员工都用铅笔写上名字和一段话：「战役结束归队」「伤愈重返连部」「立功受奖」。

展览开幕那天，来的人很多。

有个穿旧呢子大衣的老人站在第一张照片前看了很久，指着照片里那个戴军帽的小伙子，说：「这是我哥。我们一起参的军，他回来了，我没回来。」

老员工站在展板后面，听见了。

他走回办公室，从柜子最底层抽出一个上锁的铁皮箱子。钥匙在他抽屉里压了二十年，他没给别人看过。

箱子打开，里面也是档案袋。但这些档案袋上没有「战役结束归队」，写的是「失踪」「阵亡」「就地安葬」。

他数了数。

比展板上的还多。

他把箱子锁回去，关了柜子，回到展厅。访客正围着那张「立功受奖」的照片议论。有人在笔记本上抄照片背面的话。

他站在角落，手插在口袋里，没说话。

展览闭馆那天晚上，他把那五十张照片又看了一遍。每张照片上的人他都认识——他们是他亲眼看着进馆的，也是他亲眼送走的。

送走的那些，进了那个箱子。

他关上灯锁了门。

楼道里黑下来，只有监控的红点一闪一闪。

---

### 概念解析

**幸存者偏差**（Survivorship Bias）：只关注「**幸存下来 / 成功**」的样本，无视「**未幸存 / 失败**」的样本，导致对整体概率的系统性高估。

**属于**：认知偏差 / 统计学 / 战争研究

**核心定义**：当样本筛选机制与「成功」高度相关时，仅观察筛选后的样本会得到扭曲的概率判断。**最经典的案例**：二战中幸存的飞机弹痕分布不均，让统计学家沃德（Abraham Wald）意识到——**没回来的飞机才是关键样本**。

**元素映射**：

| 故事元素 | 概念对应 |
|---|---|
| 博物馆展览（只展 50 张照片） | 筛选后的样本（幸存者） |
| 照片上的人都在笑 | 显性样本的特征（成功 / 归来） |
| 铁皮箱子里的档案（失踪/阵亡/就地安葬） | 未被纳入统计的样本（沉默的另一半） |
| 「比展板上的还多」 | 沉默样本的规模（往往超过显性样本） |
| 穿呢子大衣的老人说「他回来了，我没回来」 | 沉默样本的声音（极少被听见） |
| 策展人锁回箱子、关灯离开 | 系统偏差的维持——不是因为恶意，而是因为默认 |

### 检验问题

**理解检验**：
> 故事里的策展人有没有在「撒谎」？他为什么既不撤下展览，也不把箱子打开给访客看？请从「系统维持偏差」的角度回答。

**迁移检验**：
> 假设你是一家创业公司的合伙人，正在评估要不要把资源集中到「已经融到 A 轮的几家头部公司所在的赛道」。你听说这些公司都在快速增长。如果你**只看公开报道的 A 轮公司案例**，会得出什么偏差结论？请说明这种偏差叫什么，并给出你**至少应该补看哪两类样本**才能修正判断。

## 示例 3：拓扑学 / 莫比乌斯环

**概念**：在一个二维曲面（莫比乌斯环）上，单面与单边是连通的——从一面出发可以不翻越边缘到达「另一面」，两面其实是同一个面。

**角度选择**：
- 莫比乌斯环绳子 ❌（太经典，读者已经知道答案）
- 传送带 ✅（具体工业场景 + 现代人熟悉 + 揭示过程自然）
- 蚂蚁的路线 ❌（抽象化过强）
- **采用：工厂流水线 / 传送带**（一边进一边出，工人以为两侧独立）

**切入思路**：
- 传送带 = 看起来分两侧 / 实际可能只有一侧
- 关键动作：质检员只检「正面」，但有些次品从「反面」回来
- 留痕点：质检员发现次品率统计对不上账，开始摸皮带，最后摸到「背面」其实是同一面

---

### 寓言

老周在包装厂干了七年，负责给传送带上的成品做最后一遍检查。

传送带从他面前经过，左手边是半成品进入的方向，右手边是打包入库的方向。

他把每一件拿起来，看正面，签字，放回带子。带子转过远处的弯，消失了。

七年里，他摸过几万块产品。每一块他都只摸正面。

有天，新来的统计员小陈找他核对次品率。报表上周写的次品率是 1.2%，但小陈按入库数和出厂数算，是 4.7%。

差得太多。

老周说不可能，我每一件都看过。

小陈说，师傅，您只看一面吗？

老周说，背面在另一边，归入库那边的人管。

小陈没说话。下午，传送带停机保养的时候，她跟着老周绕到传送带的另一侧。

那一侧的产品，确实也是正面朝上。

但老周蹲下去，顺着带子边缘摸了几米。他手停了。

皮带在远处的弯处没有翻转。

老周在弯曲的地方仔细看——带子在这里拧了一下，没有翻面，直接接了回去。

他蹲在那里，盯着那条拧过的接缝看了很久。

这七年，他以为自己在检两面，其实是同一面。他签字放行的每一块产品，他都只看了「一半」——那另一半从来不在他视野里。

但「另一半」也在他手上过。

只是他在签字的时候，以为那已经是他检查过的下一件。

他站起来，膝盖咯吱响。

小陈问：师傅，怎么办？

老周说：以后我检两次。

小陈问：还是只检正面？

老周想了想。

那就正面和反面都算一次，都检。

小陈说：师傅，正面反面是同一个面。

老周没说话。他把袖口往上捋了捋。

那条带子重新转起来了。

---

### 概念解析

**拓扑学**（Topology）中的**莫比乌斯环**（Möbius strip）：将一条纸带扭转 180° 后首尾相接形成的环，**只有一个面和一条边**——从一面出发可以不翻越边缘到达「另一面」。

**属于**：数学 / 几何 / 拓扑学

**核心定义**：在莫比乌斯环上，「两面」是一个**拓扑错觉**。**单连通性**意味着不存在真正的「两侧」——任何看似「对面」的位置都可以沿环面不离开地回到「正面」。

**元素映射**：

| 故事元素 | 概念对应 |
|---|---|
| 传送带的「正面 / 反面」 | 拓扑上的「两个面」（实际只有一个面） |
| 传送带在远处弯处拧了一下 | 莫比乌斯环的 180° 扭转 |
| 老周只检正面 7 年 | 单面采样（系统性漏检） |
| 次品率统计对不上 | 单面采样的后果（数据扭曲） |
| 「以后我检两次，正面反面都算一次」 | 老周的解决思路——但实际是在「同一面」上重复 |
| 小陈说「正面反面是同一个面」 | 直指拓扑事实 |

### 检验问题

**理解检验**：
> 故事里老周说「以后检两次」，为什么这个办法**仍然不够**？请用拓扑学的语言回答「为什么在莫比乌斯环上重复单面采样是无效的」。

**迁移检验**：
> 假设你在分析一家公司的「用户投诉」数据，发现客服收到的投诉量是产品反馈系统的 1/5。你原本以为这两个系统记录的是「同一组用户的两种表达」。但进一步看，两边用户 ID 几乎不重叠。此时你**应该怀疑的不只是「投诉渠道分流」，还应该怀疑什么**？请用「莫比乌斯环的错觉」类比说明，并指出正确的检查方法。

## 共同特征

每个示例都满足：
1. **不出现概念名**（用具体场景替代）
2. **2-3 个角色**（不堆角色）
3. **具体现代场景**（饺子馆 / 博物馆 / 工厂）
4. **黑名单 5 类全过**
5. **结尾留痕**（让读者合上后恍然）
6. **检验问题具体可答**（不是「你怎么看」）

## 反向学习：如果你写出来的寓言……

| 现象 | 暗示的问题 |
|---|---|
| 概念名出现在寓言中 | 没理解「寓言 = 不说破」 |
| 读者看完立刻知道讲什么 | 钩子太明显，位移不够 |
| 读者看完完全不知道讲什么 | 寓言和概念脱节，没映射 |
| 检验问题被读者随便答出来 | 问题太开放，需要更具体 |
| 字数超 1000 | 铺陈太多，精炼度不够 |
