## 2. 地名黑名单

不要写**过度文艺化的虚构地名**。这些地名本身就是 AI 写作的标志——读者一看到「回声城」「记忆之村」「遗忘之海」就知道是生成的。

### 完全黑名单

- 回声城 / 记忆之村 / 遗忘之海 / 寂静谷
- 时光镇 / 永恒城 / 命运港 / 真理山
- 月光村 / 星辰镇 / 迷雾林
- 任何「X 之 Y」结构的虚构地名

### 替换建议

**两类合规地名**：

1. **普通地理名词**（真实地名或具体场景）：
   - 「城东菜市场」/「南三环的二手车市场」/「人民医院四楼」
   - 「老城区的二手书店」/「北京西站的候车厅」

2. **不命名**（场景本身足够具体）：
   - 「电梯里」/「手术室外」/「快递分拣线」
   - 「医院的候诊椅」/「加油站的雨棚下」

## 3. 结构黑名单

5 种**过度使用的寓言结构**，命中任何一种 = 偷懒寓言。

| 结构 | 为什么禁用 | 替代方向 |
|---|---|---|
| 旅行者求教智者 | 智者角色承载了「讲道理」的功能，破坏寓言 | 让角色之间是同事 / 同伴 / 陌生人，不存在求教关系 |
| 村庄异象 → 众人顿悟 | 「众人」是一个无面群体，寓意被稀释 | 让 2-3 个具体角色各自有不同反应 |
| 孩童一句话点醒大人 | 孩童=智慧化身，套路化 | 改成任何角色（同事、邻居、陌生人）的一句话 |
| 师徒辩难 | 等级关系 = 答案倾斜 | 改成平等关系 |
| 临终遗言 | 把意义强行推到结尾 | 把意义分散到情节中 |

### 替换建议

**4 种推荐结构**（按可写性排序）：

1. **并置结构**：两个角色在做相似的事，但反应不同。一次对比，寓意自现。
   - 例：两个维修工面对同一台坏机器，一个换零件一个换整机

2. **累积结构**：同一动作反复做，每次加一点变化，最后一次让读者恍然。
   - 例：分拣员每天分拣同一类包裹，有天发现其中一类的去向变了

3. **错位结构**：角色 A 期待 X，但实际发生 Y。Y 是概念的载体。
   - 例：理赔员期待的事故没发生，但另一种「沉默的事故」一直在累积

4. **回旋结构**：开头一个动作 / 一句话，结尾同样的动作 / 一句话呼应，但意义翻转。
   - 例：开头是「她打开门」，结尾是「她关上门」——但读者知道中间发生了什么

## 4. 角色黑名单

8 种**过度使用的角色原型**，命中 = 角色是承载「讲道理」的工具人，不是真实角色。

| 角色 | 为什么禁用 | 替代候选 |
|---|---|---|
| 钟表匠 | 「手艺+时间」的偷懒组合 | 配镜师、擦鞋匠、配钥匙师傅 |
| 图书管理员 | 「知识+沉默」的偷懒组合 | 菜场摊主、夜班保安、外卖站长 |
| 隐士 | 「智慧+孤独」的偷懒组合 | 任何普通职业，配上具体场景 |
| 说书人 | 「故事+讲述」的偷懒组合 | 二手书店老板、医院导诊 |
| 老船夫 | 「经验+漂泊」的偷懒组合 | 出租车夜班司机、菜市场鱼贩 |
| 酿酒师 | 「时间+技艺」的偷懒组合 | 老式早餐店老板、配钥匙师傅 |
| 铁匠 | 「劳作+锻造」的偷懒组合 | 修表匠、裁缝、配钥匙师傅 |
| 抄经人 | 「重复+虔诚」的偷懒组合 | 快递分拣员、加油站员工、流水线工人 |

### 替换原则

**让角色是「具体职业 + 具体场景 + 具体动作」的组合**，不要让角色是「某类象征」。

- ✅「南三环二手车市场的张师傅，蹲在车底检查底盘」（具体）
- ❌「一位老船夫」（抽象 + 黑名单）

## 5. 开头黑名单

3 种**过度使用的开头**——读者看到第一句就猜到是寓言/AI 生成。

| 开头 | 为什么禁用 | 替代开头 |
|---|---|---|
| 「从前有个地方……」 | 童话套路，钩子失效 | 「下午三点，南三环二手车市场的张师傅接到一通电话」（具体时间地点人物） |
| 「某天某人遇见某事……」 | 抽象、零信息 | 「理赔员老周打开第三个档案袋，里面的照片让他停下了手」（具体动作 + 悬念） |
| 「在很远的山里……」 | 文艺腔，AI 味 | 「夜班护士推开 412 病房的门，床是空的」（直接进场景 + 异常） |

### 替换建议（5 种合规开头模板）

1. **具体时间 + 具体地点 + 具体动作**：
   - 「下午两点，东直门医院四楼的候诊椅上，李护士翻开病历夹。」

2. **直接进异常**：
   - 「分拣员老赵盯着第 47 号包裹，标签上的地址他认识——但寄件人已经搬走三个月了。」

3. **对话开头**：
   - 「'这批货退不了。' 菜场摊主把塑料袋往秤上一扔。」

4. **动作开头（无对话）**：
   - 「配镜师从抽屉里拿出第三副眼镜，镜腿折过两次，胶水粘过三次。」

5. **场景特写开头**：
   - 「凌晨四点的加油站只有一辆车，计价器跳到了 287.6。」

## 黑名单自检流程

写完寓言后，按顺序过：

```
1. 意象 grep：搜索黑名单 18 个意象，任何命中 → 重写
2. 地名 grep：搜索「XX 之 YY」结构、文艺化地名 → 重写
3. 结构检查：是否符合 5 种禁用结构 → 重写
4. 角色检查：是否是 8 种禁用角色 → 替换
5. 开头检查：第一句是否命中 3 种禁用开头 → 重写开头
```

5 项全过 = 寓言结构合规，可以进入下一步（写概念解析 + 检验问题）。

## 黑名单的元原则

> 黑名单不是「禁止这些词」，而是「禁止这些词所代表的偷懒」。
>
> 钟不是不能用——如果你能写出「这只钟的秒针在某一天停了三秒，而那一天发生的事没人记录」这种全新的用法，钟就不是偷懒。
>
> 但默认情况下，黑名单内的词**已经承载了太多刻板含义**，用它们 = 与你的读者抢语义控制权。**新词比旧词更有力**，因为旧词已经被用尽了。
