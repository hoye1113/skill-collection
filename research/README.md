## 使用场景

- 进入新市场前验证机会大小
- 系统性地拆解竞品策略与漏洞
- 追踪行业趋势并判断生命周期阶段
- 优化内容在 AI 搜索引擎中的可见性
- 从 Reddit 真实讨论中提取用户痛点
