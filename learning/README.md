# Learning

知识学习与成长类 Skills —— 覆盖系统化阅读、知识库构建、自适应学习。

## Skills

| Skill | 说明 | 来源 |
|-------|------|------|
| [book-study](book-study/) | 系统化阅读教练：章节精读、知识编译、苏格拉底式测试、间隔复习 | sanyuan-skills |
| [kb-retriever](kb-retriever/) | 本地知识库检索助手，支持 PDF/Excel 等混合格式 | garden-skills |
| [sigma](sigma/) | Bloom 2-Sigma 精通学习 AI 家教：苏格拉底式提问、自适应诊断 | sanyuan-skills |
| [wiki-ingest](wiki-ingest/) | 将文章/文档/笔记编译为带双向链接的结构化 Wiki | sanyuan-skills |
| [learn](learn/) | 元技能：教 Claude 学习任意主题并保留为永久 skill | claude-skills-library |
| [deep-interview](deep-interview/) | 自适应深度访谈提取知识，ASK-LISTEN-WRITE-DEEPEN 循环 | claude-skills-library |

## 使用场景

- 跟着 AI 系统化地读完一本书
- 从本地文档库中检索和问答
- 构建个人或团队的 Wiki 知识库
- 对某个主题进行苏格拉底式深入学习
