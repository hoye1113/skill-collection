## 使用场景

- 生成海报、UI 概念图、产品图、信息图等视觉素材
- 制作演讲/分享/发布会风格的网页 PPT
- 为即梦 Seedance 2.0 编写高质量视频生成提示词
- 将文章或脚本转为可录屏的交互式网页演示
